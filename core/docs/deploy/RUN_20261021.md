## Decisions I took that were not handed to me

1. **Revenue is shown at all, and with the definitions the customers screen already uses.** The old page refused
   to show money because "the definition is open". It is not open: `Customers` already defines **sold** as
   `status <> cancelled` and **delivered** as `delivered|completed`. Inventing a second definition on this page
   is how two screens come to disagree, so these are the same two.
2. **The work queue is not windowed.** It costs an index; it buys the old pending order, which is the point.
3. **"Reorder" means the best sellers that ran out**, not anything that sold once and ran out — a consequence of
   merging the two aggregations, and better as a rule.
4. **An index migration.** The brief said build a fast page, not add an index; the index is what makes the most
   useful block on the page affordable, it is additive and reversible, and its cost is one more write per order.
5. **The storefront default is combined, not per shop**, with the catalogue numbers labelled as shared.
6. **`orders_unseen` ignores the page's switch** so it can never disagree with the sidebar badge.
7. **The synthetic order history.** 250,000 generated orders on a scratch copy is the only way to time this
   honestly; the alternative was to quote 29 local orders or to guess. The rows are generated, labelled, and the
   database was dropped.

## What I could not answer, and the query that would

Production's order history. Everything above is timed against synthetic rows at a scale I chose; the real cost
depends on numbers only Michael can read:

```sql
SELECT COUNT(*) AS orders, MIN(created_at) AS first_order, MAX(created_at) AS last_order FROM orders;
SELECT status, COUNT(*) FROM orders GROUP BY status;        -- how much of the table the open-order range covers
```

If the first answers a few thousand, the index changes nothing measurable and the page is quick either way; it
was still worth adding, because it is the difference between a page that stays quick and one that degrades
quietly as the shop grows.
