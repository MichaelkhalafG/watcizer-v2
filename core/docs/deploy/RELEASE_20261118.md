   It opens four database connections, 5 s apart, and retries a refused one with backoff. It ends with
   "== DONE - nothing was written to the database" only when both dumps are whole, end with mysqldump's completion line
   and hold every table that has rows. Any other end prints "*** STOP" and "*** NOT DONE" and deletes the partial
   files: then send the log, nothing else.
